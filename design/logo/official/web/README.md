# 總會官方 logo：網站清晰版（待 Steven 批准）

原檔 `../mcka-logo-official.jpg` 得 406×230，綠色漸變底，喺高清螢幕會矇。呢度係唔改設計嘅向量重製版：

- 主體（球、Macau 草書、China、籃同柱）係由原圖描出嚟，形狀照跟原圖。
- 底下「KORFBALL ASSOCIATION」原圖筆畫得 1 像素，描唔到，所以用相近嘅闊體字 Michroma（免費 OFL 字體，已轉做路徑）重排，位置同長度對準原圖。
- 去咗綠色漸變底，透明背景，可以用任何單色。

檔案：
- `mcka-logo-navy.svg` / `-600.png` / `-1200.png`：深藍 #14213D，白底用（方案一）
- `mcka-logo-green.svg` / PNG：總會綠 #0B6A12，白底用（方案二）；白底對比 6.8
- `mcka-logo-white.svg` / PNG：白色，深色或者綠色底用
- `compare-original-vs-vector.png`：原圖同重製版對照
- `header-options.png`：網站頂欄兩個配色方案
- `build_logo.py`：重製腳本（需要 potrace）

注意：logo 縮到頂欄高度（約 58px）時，底下英文細字只得 2px 高睇唔到，所以頂欄旁邊照放中英文總會名。
