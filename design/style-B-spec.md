# 風格 B 規格：運動活力・深藍＋橙（Steven 2026-10-03 揀定）

## 顏色（CSS 變數）
```css
:root{
  --bg:        #0F1B33; /* 頁面底色 */
  --hero:      #14213D; /* 頂部大圖底，斜紋配 #182A4D */
  --hero-2:    #182A4D;
  --card:      #1B2A4A; /* 卡片 */
  --line:      #2B3F69; /* 分隔線、相片佔位 */
  --accent:    #FF7A00; /* 橙：標題、按鈕、現時頁面底線 */
  --text:      #FFFFFF;
  --text-2:    #B8C2D6; /* 次要文字：日期、說明 */
  --sample:    #FFD54A; /* 只限「示例」橫額，上線前移除 */
}
```
對比度（WCAG）：橙字配深藍底 6.1:1，白字配深藍 16:1，次要字 #B8C2D6 配卡片 7.9:1，全部過 AA。
**唔好用橙字配白底**（只有 2.6:1，睇唔清）。如果將來要白底頁（例如列印版），橙色改用 #C25700。

## 字體（只載兩個粗幼度）
- 中文：Noto Sans TC 400（內文）／700（標題、按鈕）
- 英文同數字：同一套 Noto Sans TC 已包，唔另外載入，減少檔案。
- 標題大細（手機／電腦）：大標題 32/56px，分區標題 22/26px，內文 16px，行距 1.6。
- 英文版分區標題用大楷，字距 1px；中文唔使。

## 元件
- 按鈕：橙底深藍字，圓角 6px，padding 12px 22px，700 粗。
- 卡片：#1B2A4A，圓角 6px，padding 16px；右邊標籤白底深藍字，圓角 10px。
- 導航：現時頁面用橙字加 2px 橙底線；頂欄底部 3px 橙線。
- 相片格：圓角 4px，手機 2 欄、電腦 3 欄，比例 4:3，object-fit: cover。
- 斜紋：repeating-linear-gradient(-55deg, var(--hero) 0 22px, var(--hero-2) 22px 44px)，只用喺頂部大圖區。

## 手機版注意
- 6 個頁面導航喺 390px 闊度會爆出去（「證書課程」被切走）。建議：手機版改用「選單」掣展開，或者保留橫向捲動但右邊加漸變提示有更多。
- 點擊範圍最少 44×44px。
